# GitLite 🚀  
### A Simplified Git/GitHub Simulation Using Data Structures and Algorithms

GitLite is a Java-based Version Control System inspired by Git and GitHub.  
This project was developed as a **DSA Semester Project** to demonstrate the practical implementation of fundamental Data Structures and Algorithms in a real-world software application.

GitLite allows users to create repositories, manage files, track commits, create branches, simulate push/pull operations, and collaborate with contributors using custom-built DSA implementations.

# 🧠 Data Structures Used

| Data Structure | Purpose |
|---|---|
| Stack | Undo/Redo Operations |
| Linked List | Commit History |
| Binary Search Tree (BST) | Commit Searching |
| Hash Map | Fast Repository/File Lookup |
| Arrays | Staging Area & Storage |
